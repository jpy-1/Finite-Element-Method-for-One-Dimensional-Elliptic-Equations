# Finite-Element-Method-for-One-Dimensional-Elliptic-Equations
使用有限元方法（FEM）求解以下边值问题：
$$-u^{\prime \prime} = \sin(4x), \quad x \in \left[0, \frac{\pi}{8}\right]$$

边界条件为：
$$u(0) = u^{\prime}\left(\frac{\pi}{8}\right) = 0$$

提供了两种基函数的有限元实现：
- 分片线性多项式（k=1）
- 分片二次多项式（k=2）

## 文件说明
后缀为1表示求解一次元，后缀为2为二次元
| 文件名 | 功能描述 |
|--------|----------|
| `Fem_class.m` | 定义方程基本参数 |
| `Fun_fem.m` | 有限元求解函数输出数值解 |
| `Error_compute.m` | 计算数值解的 $L^1,L^2,L^{\infty}$ 误差 |
| `Convergence_order_compute.m` | 主函数，计算误差的收敛阶 |
| `Figure_make.m` | 绘制数值解与解析解的对比图 |

## 使用说明

1. 运行 `Fem_class.m` 设置方程参数。
2. 调用 `Fun_fem_1.m` 或 `Fun_fem_2.m` 进行求解。
3. 使用 `Error_compute.m` 计算误差。
4. 使用 `Convergence_order_compute.m` 计算收敛阶。
5. 使用 `Figure_make.m` 生成图像。
